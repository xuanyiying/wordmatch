# 应用图标设计指南

## 现状

当前项目使用的是 **Flutter 默认图标**（蓝色 Flutter Logo + "F" 字母）。

**⚠️ 强烈建议** 上架前替换为自定义图标，体现"单词消消乐"主题。

## 图标设计要素

### 1. 核心元素
- **单词 / 字母**：突出"单词"主题
- **配对 / 消除**：体现"消消乐"玩法
- **明亮配色**：体现"趣味"和"活力"

### 2. 推荐设计方案

#### 方案 A：字母+配对
- 主体：大写字母 "W"（WordMatch）
- 配色：蓝紫渐变
- 装饰：配对连接线

#### 方案 B：两个字母方块配对
- 主体：两个相对方块（一个 "A"，一个 "中"）
- 配色：橙绿对比
- 装饰：配对连线

#### 方案 C：单词卡片
- 主体：一对单词卡片
- 配色：暖色调
- 装饰：勾选符号

#### 方案 D：抽象图案
- 主体：抽象的"配对"图案
- 配色：渐变彩色
- 装饰：星星 / 光晕

## Android 自适应图标

Android 8.0+ (API 26) 支持自适应图标：
- **前景 (108×108dp)**：核心元素
- **背景**：纯色或简单图案
- **安全区**：中心 72×72dp（防止被系统裁剪）

### 文件结构
```
android/app/src/main/res/
├── mipmap-anydpi-v26/
│   ├── ic_launcher.xml      # 自适应图标配置
│   └── ic_launcher_round.xml # 圆形图标
├── mipmap-mdpi/
│   ├── ic_launcher.png      # 48x48
│   └── ic_launcher_round.png
├── mipmap-hdpi/
│   ├── ic_launcher.png      # 72x72
│   └── ic_launcher_round.png
├── mipmap-xhdpi/
│   ├── ic_launcher.png      # 96x96
│   └── ic_launcher_round.png
├── mipmap-xxhdpi/
│   ├── ic_launcher.png      # 144x144
│   └── ic_launcher_round.png
├── mipmap-xxxhdpi/
│   ├── ic_launcher.png      # 192x192
│   └── ic_launcher_round.png
└── drawable/
    └── ic_launcher_foreground.xml  # 前景（108x108）
    └── ic_launcher_background.xml  # 背景（颜色或图案）
```

### 自适应图标 XML 模板

`mipmap-anydpi-v26/ic_launcher.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```

`drawable/ic_launcher_background.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <solid android:color="#3498DB"/>
</shape>
```

`drawable/ic_launcher_foreground.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="108dp"
    android:height="108dp"
    android:viewportWidth="108"
    android:viewportHeight="108">
    <!-- 在 18-90 范围内设计（72dp 中心区） -->
    <path
        android:fillColor="#FFFFFF"
        android:pathData="M30,30 L78,30 L78,78 L30,78 Z M40,40 L40,68 M50,40 L50,68 M60,40 L60,68 M70,40 L70,68" />
</vector>
```

## 快速替换方法

### 方法 1：使用 `flutter_launcher_icons` 插件（推荐）

```yaml
# pubspec.yaml
dev_dependencies:
  flutter_launcher_icons: ^0.13.1

flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon/icon.png"  # 1024x1024 PNG
```

然后运行：
```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

### 方法 2：手动替换

1. 准备一张 1024×1024 的 PNG 图标
2. 使用 https://www.appicon.co/ 生成各尺寸
3. 替换 `android/app/src/main/res/mipmap-*/ic_launcher.png`

## 设计原则

### ✅ DO
- 简洁明了，一眼识别
- 颜色饱和、有活力
- 中心元素突出
- 适配深色 / 浅色模式

### ❌ DON'T
- 文字过小看不清
- 元素过于复杂
- 颜色对比度低
- 容易被裁剪的关键元素在边缘
