### 5. 软件功能和技术特点描述

> **重要：2026年新规要求此部分字数为500-1300字，请严格按照以下内容填写，勿增删。**

单词消消乐软件是一款基于Flutter框架开发的英汉词汇学习移动应用，将经典消除游戏机制与科学记忆算法深度融合，实现寓教于乐的英语单词学习体验。软件核心功能和技术特点如下：

一、核心消除玩法：软件提供小网格（4/8/12对）与大网格（18对）两种网格模式，卡牌区每行固定4列、行数随配对数自适应，将英文单词与对应中文释义以卡片形式随机排列在网格中。用户通过依次点击英文卡片和中文卡片进行配对，匹配正确则卡片消除并得分，匹配错误则卡片翻回。系统内置消歧机制，当多个中文释义相近时自动提示用户选择目标词义，确保学习准确性。游戏支持连击（Combo）机制，连续正确匹配可获得倍率加分，增强游戏激励性。

二、SM-2间隔重复算法：软件采用经典的SuperMemo SM-2算法驱动复习调度。每次匹配后用户对单词掌握程度进行0-5级质量评分，系统根据评分动态计算下次复习间隔（1天至数月不等），并维护复习债务上限机制，确保积压的待复习单词不会无限累积。算法参数包括易度因子（EF）、间隔天数和重复次数，全部本地计算，无需联网。

三、词库管理：软件内置CET-4、CET-6、考研、高考、IT等多个词库，支持按领域（如成语、IT、诗歌等）分类选择。用户可通过导入自定义词库文件扩展学习内容，导入时提供AI清洗功能，自动识别并修正格式错误、重复词条和缺失释义，保障词库质量。

四、学习计划引擎：根据用户设定的每日学习时长和目标词汇量，自动计算每日新词推送数量，结合SM-2算法生成的复习任务，智能安排每日学习计划。引擎考虑时长约束，确保学习负担可控，避免计划过载。

五、错词本与复习功能：软件自动收集用户匹配错误的单词，生成错词本。用户可随时查看错词列表，并针对错词进行专项复习，通过反复练习强化薄弱词汇的记忆。

六、多主题切换：软件提供学术（Academic）、森林（Forest）、太空（Space）三套视觉主题，每套主题包含独立的背景图、卡片样式、配色方案和亮色/暗色模式适配，用户可自由切换，提升使用体验的个性化和新鲜感。

七、音效与触觉反馈：消除匹配、连击、匹配失败等关键操作均配有专属音效，同时集成触觉反馈（Haptic Feedback），在匹配成功和失败时提供不同强度的振动提示，增强操作手感。

八、数据本地存储与隐私保护：所有用户数据（学习进度、复习记录、错词本、主题偏好等）均通过SharedPreferences和SQLite（drift）存储在本地设备，不采集、不上传任何用户个人信息，无云端服务器依赖。应用仅申请INTERNET权限（用于词库资源加载），充分保障用户隐私安全。

## 三、2026年新规注意事项

### 1. 新版申请表要求

自2026年3月15日起，中国版权保护中心启用新版软件著作权登记申请表。新版申请表在原有基础上增加了诚信承诺、原创性声明等内容，旧版表格不再受理。请务必从官网下载最新版申请表，切勿使用旧版模板。

### 2. 诚信说明要求

新版申请表要求经办人亲笔抄写诚信说明全文并签名。具体要求：
- **必须手写**：诚信说明需由经办人亲笔抄写，不接受打印件
- **签名**：抄写完成后手写签名
- **身份证号**：需同时手写填写经办人身份证号码
- **字迹清晰**：确保字迹工整、可辨认，涂改处需按手印确认

### 3. AI查重机制

2026年新规引入源代码AI查重机制，对提交的源代码进行原创性检测：
- 系统将自动比对已登记软件的源代码库
- 相似度过高的申请将被标记并进入人工复核
- 使用AI生成代码需确保经过实质性修改和创造性加工
- **建议**：提交的源代码前后各连续30页（共60页）应选择核心业务逻辑部分，避免提交框架自动生成的样板代码

### 4. 实质审查升级

审查方式从形式审查升级为有限实质审查：
- 审查员有权要求申请人补充说明软件功能和技术特点
- 可能要求提供软件运行截图或演示视频
- 对存疑申请可启动质询程序，要求申请人到场说明
- 审查周期可能因此延长，建议提前准备补充材料

### 5. 非正常登记行为禁止

以下行为被明确列为非正常登记行为，一经发现将严肃处理：
- **代码注水**：通过大量注释、空行、重复代码等方式人为增加源程序行数
- **材料造假**：伪造开发完成日期、首次发表日期、身份信息等
- **抄袭剽窃**：提交他人软件的源代码申请登记
- **批量登记**：短期内提交大量低质量软件登记申请

**后果**：
- 撤销已登记的软件著作权
- 纳入不良信用记录
- 限制后续登记申请
- 情节严重者依法追究法律责任

### 6. 软件功能说明字数要求

2026年新规将软件功能和技术特点描述的字数要求从原来的200字扩展至**500-1300字**：
- 低于500字将被退回补正
- 超过1300字需精简
- 内容应真实、准确、具体，避免空泛描述
- 建议按功能模块分点描述，逻辑清晰

## 四、申请流程概述

### 完整流程

```
中国版权保护中心官网注册
        ↓
    实名认证（个人/企业）
        ↓
    在线填报申请表
        ↓
    上传申请材料
        ↓
    缴纳费用（自助申请免费）
        ↓
    等待审核
        ↓
    审核通过 → 领取证书
    审核不通过 → 补正后重新提交
```

### 各环节说明

| 环节 | 说明 |
|------|------|
| 官网注册 | 访问中国版权保护中心官网（https://www.ccopyright.com.cn），注册账号 |
| 实名认证 | 个人需上传身份证并人脸识别；企业需上传营业执照并经办人实名认证，通常1-3个工作日完成 |
| 在线填报 | 按照本指南第一部分内容逐项填写，注意字数要求 |
| 上传材料 | 身份证明文件、源代码前后各连续30页、软件鉴别材料等 |
| 审核 | 普通审核40-60个工作日；加急审核5-10个工作日 |
| 领证 | 审核通过后可在线下载电子证书，或选择邮寄纸质证书 |

### 费用说明

| 类型 | 费用 |
|------|------|
| 自助申请 | 免费 |
| 代理机构代办 | 根据机构报价，通常500-2000元 |
| 加急服务 | 按加急天数收费，具体以官网公示为准 |

### 需上传的核心材料清单

1. 软件著作权登记申请表（在线填报后自动生成）
2. 申请人身份证明文件
3. 源代码前后各连续30页（每页不少于50行，共约60页）
4. 软件鉴别材料（用户手册或操作说明书，前后各连续30页）

## 五、材料一致性检查清单

> **核心原则：同一信息在所有材料中必须完全一致，一个字的差异都可能导致退回补正。**

### 关键一致性检查项

| 检查项 | 检查内容 | 常见错误 |
|--------|----------|----------|
| 软件全称 | 申请表软件全称为"单词消消乐软件"；源代码页眉应标注"单词消消乐软件 V1.0"；设计说明书封面使用"单词消消乐软件" | "单词消消乐软件" vs "单词消消乐"（缺少"软件"二字） |
| 版本号 | 所有材料中的版本号必须统一 | "V1.0" vs "v1.0" vs "1.0" |
| 著作权人名称 | 必须与身份证明文件上的名称一字不差 | 身份证姓名 vs 常用名/笔名；营业执照上的企业全称 vs 简称 |
| 开发完成日期 | 不晚于首次发表日期 | 逻辑矛盾 |
| 源代码中的版权声明 | 代码页眉或注释中的软件名称、版本号应与申请表一致 | 遗漏或名称不一致 |

### 逐项核对表

- [ ] 申请表软件全称"单词消消乐软件" = 源代码页眉"单词消消乐软件 V1.0"中的软件名称 = 设计说明书封面"单词消消乐软件"
- [ ] 申请表版本号 = 源代码页眉版本号 = 用户手册中提及的版本号
- [ ] 著作权人姓名 = 身份证姓名（个人）/ 营业执照企业全称（企业）
- [ ] 开发完成日期 ≤ 首次发表日期
- [ ] 源代码页数 ≥ 60页（前后各30页），每页 ≥ 50行
- [ ] 用户手册页数 ≥ 60页（前后各30页）
- [ ] 所有扫描件清晰可辨，身份证在有效期内
- [ ] 诚信说明已亲笔抄写并签名
- [ ] 申请表所有必填项已填写，无空白项
