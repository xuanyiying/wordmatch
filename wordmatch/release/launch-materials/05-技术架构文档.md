### 2.3 各层职责

**UI 表现层（Presentation）**：
- Flutter Widgets + 自定义组件
- screens/：各页面，负责 UI 布局和用户交互
- widgets/：可复用组件，负责单一 UI 元素渲染
- 通过 Riverpod Provider 获取数据，不直接访问数据层

**业务逻辑层（Domain）**：
- 纯 Dart Services，不依赖 Flutter 框架
- match_service.dart：匹配逻辑判断
- sm2_service.dart：SM-2 间隔重复算法
- plan_service.dart：学习计划生成与调整
- difficulty_service.dart：动态难度调整
- root_engine.dart：词根拆解引擎
- disambiguation_service.dart：消歧服务

**数据层（Data）**：
- Repositories + DataSources + Models
- game_provider.dart：游戏状态管理（Riverpod StateNotifier）
- word_repository.dart：词库数据读写
- wordbook_repository.dart：词库管理
- progress_storage.dart：学习进度存储（SharedPreferences）
- app_database.dart：SQLite 数据库定义（drift）

**核心层（Core）**：
- theme/：主题系统（4 套主题 + 亮暗色）
- router/：路由配置
- constants/：常量定义（颜色、尺寸、字符串）
- settings/：设置页面

## 3. 核心数据结构

### 3.1 Words 表（词库表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | TEXT | 主键 | 单词唯一 ID |
| word | TEXT | 非空 | 单词文本 |
| phoneticUs | TEXT | 可空 | 美式音标 |
| phoneticUk | TEXT | 可空 | 英式音标 |
| definition | TEXT | 非空 | 释义（JSON 数组格式） |
| exampleSentence | TEXT | 可空 | 例句 |
| frequency | INTEGER | 默认 3 | 词频等级（1-5） |
| bookId | TEXT | 非空 | 所属词书 ID |
| rootParts | TEXT | 可空 | 词根拆分 |
| hasMnemonic | BOOLEAN | 默认 false | 是否有记忆技巧 |
| createdAt | DATETIME | 默认当前时间 | 创建时间 |

### 3.2 UserWordProgress 表（用户单词进度表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| wordId | TEXT | 主键 | 单词 ID |
| bookId | TEXT | 非空 | 词书 ID |
| easinessFactor | REAL | 默认 2.5 | 难度因子（SM-2 算法） |
| intervalDays | INTEGER | 默认 0 | 复习间隔天数 |
| repetitions | INTEGER | 默认 0 | 复习次数 |
| nextReviewDate | DATETIME | 非空 | 下次复习日期 |
| lastQuality | INTEGER | 默认 0 | 最近一次质量评分（0-5） |
| isMastered | BOOLEAN | 默认 false | 是否已掌握 |
| reviewDebt | INTEGER | 默认 0 | 复习债务 |
| createdAt | DATETIME | 默认当前时间 | 创建时间 |
| updatedAt | DATETIME | 默认当前时间 | 更新时间 |

### 3.3 GameSessions 表（游戏对局记录表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | 自增主键 | 对局唯一 ID |
| bookId | TEXT | 非空 | 词书 ID |
| domainId | TEXT | 可空 | 领域 ID（领域游戏时使用） |

| matchCount | INTEGER | 默认 0 | 匹配成功数 |
| errorCount | INTEGER | 默认 0 | 错误次数 |
| hintCount | INTEGER | 默认 0 | 使用提示次数 |
| durationMs | INTEGER | 非空 | 游戏时长（毫秒） |
| maxCombo | INTEGER | 默认 0 | 连击最高记录 |
| score | INTEGER | 默认 0 | 得分 |
| isCompleted | BOOLEAN | 默认 false | 是否完成 |
| startTime | DATETIME | 非空 | 开始时间 |
| endTime | DATETIME | 可空 | 结束时间 |
| createdAt | DATETIME | 默认当前时间 | 创建时间 |

### 3.4 LearningPlans 表（学习计划表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | 自增主键 | 计划唯一 ID |
| bookId | TEXT | 非空 | 词书 ID |
| examDate | DATETIME | 非空 | 考试/目标日期 |
| dailyMinutes | INTEGER | 非空 | 每日学习时长（分钟） |
| dailyNewWords | INTEGER | 默认 20 | 每日新词目标 |
| learnedDays | INTEGER | 默认 0 | 已学习天数 |
| isActive | BOOLEAN | 默认 true | 是否激活 |

> 数据库共定义 `words`、`user_word_progress`、`game_sessions`、`learning_plans` 四张表（见 `app_database.dart`）。

## 5. 安全设计

### 5.1 数据安全

- **本地存储优先**：所有学习数据、进度数据全部存储在设备本地，无云端传输
- **数据库安全**：SQLite 数据库文件存储在应用沙盒目录，其他应用无法访问
- **键值存储安全**：SharedPreferences 存储在应用沙盒，系统级保护

### 5.2 网络安全

- **HTTPS 通信**：所有网络请求（TTS 发音、AI 清洗）均使用 HTTPS 加密传输
- **最小网络依赖**：核心功能（消除游戏、SM-2 复习、词库学习）完全离线可用
- **网络功能可选**：AI 清洗、TTS 发音为可选功能，用户可自主选择是否启用

### 5.3 密钥安全

- **API Key 本地存储**：AI API Key 仅存储在设备本地（SharedPreferences）
- **不传输密钥**：API Key 不会上传到任何第三方服务器
- **用户自主配置**：API Key 由用户自行配置，应用不预设任何密钥

### 5.4 隐私保护

- **无用户身份收集**：不收集任何用户身份信息（姓名、邮箱、手机号等）
- **无行为追踪**：不集成任何第三方统计 SDK，不追踪用户行为
- **无数据共享**：不与任何第三方共享用户数据
- **离线优先**：核心功能无需网络，最大限度保护用户隐私
