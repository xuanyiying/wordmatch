## 1. 功能概述

### 1.1 应用定位

单词消消乐是一款将经典消除游戏与科学记忆算法深度融合的英语词汇学习应用。通过英汉匹配消除的即时多巴胺反馈机制，让用户在游戏过程中自然完成词汇记忆；结合 SM-2 间隔重复算法确保长期记忆效果；AI 大模型提供词根拆解、消歧等深度助学能力。

### 1.2 目标用户

- 高中生：备战高考，需掌握高考 3500 词
- 大学生：备考 CET-4/CET-6，需系统背词
- 考研群体：考研大纲词汇复习
- IT 从业者：专业英语词汇提升
- 语言爱好者：成语、古诗词等特色领域学习

### 1.3 核心价值主张

- **即时反馈**：消除玩法的视觉、听觉、触觉三重反馈，让背词不再枯燥
- **科学记忆**：SM-2 算法自动安排复习，用最少时间达到最佳记忆效果
- **智能助学**：AI 大模型提供词根拆解、消歧等深度学习辅助
- **离线可用**：数据全部本地存储，无需网络即可学习

### 1.4 功能架构

## 2. 功能模块详细说明

### 2.1 核心消除玩法

**功能描述**：英汉匹配消除游戏，将英文单词与对应中文释义配对消除。

**网格规格**：

| 规格 | 配对数 | 适用场景 |
|------|--------|----------|
| 小网格（每行 4 列） | 4 / 8 / 12 对卡牌 | 新词学习，适合入门和快速记忆 |
| 大网格（每行 4 列，9 行可滚动） | 18 对卡牌 | 复习巩固，适合大量词汇回顾 |

每局配对数可在设置中选择（默认 8 对），卡片总数为配对数 × 2。

**卡牌类型**：
- 英文卡牌：显示英文单词
- 中文卡牌：显示中文释义

**匹配规则**：
- 选择一张英文卡牌和一张中文卡牌，若为同一词条则匹配成功消除
- 不限制选择顺序（先英后中或先中后英均可）

**匹配成功反馈**：
- 卡牌吸附爆裂成粒子特效
- 播放单词发音（TTS）
- 清脆音效（match_success.mp3）

**匹配失败反馈**：
- 卡牌抖动动画
- 沉闷音效（match_fail.mp3）
- 触觉反馈（设备振动）

**Combo 连击系统**：
- 连续 3 次匹配成功触发 Combo 效果
- 屏幕边缘泛光
- 音调升高（combo.mp3）
- 连击数实时显示

**防死局机制**：
- 后台校验可消除路径
- 连续 3 次错误自动高亮提示
- 确保游戏始终可完成

**动态难度调整**：
- 正确率 > 90% 时增加形近词/义近词干扰项
- 正确率较低时减少干扰项
- 根据用户表现实时调整

### 2.2 词库管理

**内置词库**：

| 词库名称 | 词汇量 | 目标群体 |
|----------|--------|----------|
| 高考 3500 词 | ~3500 | 高中生 |
| CET-4 核心词 | ~2000 | 大学生（四级） |
| CET-6 核心词 | ~2500 | 大学生（六级） |
| 考研大纲词 | ~5500 | 考研群体 |
| IT 专业词汇 | ~500 | IT 从业者 |

**领域词库**：

| 领域 | 说明 |
|------|------|
| 成语 | 中文成语学习 |
| IT 术语 | 信息技术专业术语 |
| 古诗词 | 古典诗词鉴赏 |

**自定义导入**：
- 支持粘贴文本导入自定义词库
- 支持批量导入

**AI 智能清洗**（可选功能）：
- 调用大模型 API 清洗杂乱词库文本
- 自动识别和修正格式问题
- 用户可自主选择是否启用

### 2.3 学习计划引擎

**自动生成学习计划**：
- 根据词库总量、已掌握量、剩余天数、每日时长自动计算
- 每日新词量 = (总量 - 已掌握) / 剩余天数 × 1.2
- 时长约束：1 分钟处理 1.5 个新词或 3 个复习词

**复习债务管理**：
- 每日最多 200 个复习词
- 超出部分分摊到后续日期
- 债务期间新词自动减半

**计划参数**：

| 参数 | 说明 |
|------|------|
| 词书 ID | 关联的词库 |
| 考试/目标日期 | 学习截止日期 |
| 每日学习时长 | 用户设定的每日学习分钟数 |
| 每日新词目标 | 自动计算或手动设定 |
| 已学习天数 | 系统自动累计 |

### 2.4 SM-2 间隔重复算法

**质量评分（0-5）**：基于匹配耗时和错误次数自动计算

| 评分 | 条件 | 记忆状态 |
|------|------|----------|
| Q=5 | 秒配无错误 | 熟练 |
| Q=3 | 思考超 3 秒或错 1 次 | 模糊 |
| Q=1 | 错 2 次以上或使用提示 | 陌生 |

**复习间隔规则**：
- Q < 3：重置为 1 天
- Q >= 3：递增（1 天 → 6 天 → 按难度因子递增）

**难度因子**：
- 初始值：2.5
- 最低值：1.3
- 根据 Q 值动态调整

**掌握判定**：
- 间隔 > 21 天视为已掌握

### 2.5 新词学习

**卡片式学习流程**：
- 逐词展示，15 秒/词
- 显示单词、音标、释义、例句
- 支持词根拆解展示（如有）

**认识/不认识判定**：
- 认识：标记为已学习，进入复习队列
- 不认识：标记为需加强，优先进入消除游戏巩固

**学习完成后**：
- 自动进入消除游戏巩固
- 游戏中包含刚学的单词

### 2.6 错词本

**功能描述**：自动记录匹配错误的单词，支持针对性重练。

**核心功能**：
- 自动记录匹配失败的单词
- 记录错误次数（按降序排列）
- 记录最近 5 条错误上下文
- 支持查看错词详情
- 支持重练（消除游戏）
- 重练通关后自动移出错词本

**数据结构**：

| 字段 | 说明 |
|------|------|
| wordId | 单词 ID |
| bookId | 词书 ID |
| wrongCount | 错误次数 |
| lastWrongAt | 最近错误时间 |
| wrongContexts | 错误上下文列表（最多 5 条） |

## 3. 功能交互逻辑

### 3.1 主要用户流程

```
首次启动 → 引导页（3页）→ 选择词库 → 首页
```

```
首页 → 新词学习 → 消除游戏 → 学习报告 → 首页
```

```
首页 → 复习 → 消除游戏 → 学习报告 → 首页
```

```
首页 → 错词本 → 重练（消除游戏）→ 首页
```

```
首页 → 设置 → 各设置项
```

### 3.2 游戏流程

```
选择模式（新词/复习/错词重练）
    ↓
生成网格（每行 4 列，小网格或大网格）
    ↓
选择卡牌 → 判断匹配
    ├── 匹配成功 → 粒子特效 + 发音 + 音效 → 判断连击
    └── 匹配失败 → 抖动 + 音效 + 触觉 → 判断是否需要提示
    ↓
全部消除 → 生成学习报告 → 更新 SM-2 进度
```

### 3.3 学习计划流程

```
选择词库 → 设定目标日期和每日时长
    ↓
自动生成学习计划
    ↓
每日执行：新词学习 + 复习
    ↓
SM-2 算法更新进度
    ↓
动态调整每日任务量
```

## 4. 数据流转说明

### 4.1 词库数据流

```
内置 JSON 文件（assets/data/、assets/domains/）
    ↓ 启动时加载
本地数据源（LocalWordDataSource）
    ↓ 解析入库
SQLite 数据库（Words 表）
    ↓ 查询
词库仓库（WordRepository / WordbookRepository）
    ↓ 提供
UI 展示
```

### 4.2 学习进度流

```
游戏操作（匹配成功/失败）
    ↓ 记录表现
GameState.wordPerformance
    ↓ 计算 SM-2 评分
SM2Service.calculateReview()
    ↓ 更新进度
ProgressStorage / UserWordProgress 表
    ↓ 筛选
复习队列（nextReviewDate <= 今天）
```

### 4.3 设置数据流

```
用户操作（主题切换、API 配置等）
    ↓ 存储
SharedPreferences
    ↓ 读取
全局状态（Riverpod Providers）
    ↓ 响应
UI 更新
```

### 4.4 游戏记录流

```
游戏开始 → 创建 GameSession 记录
    ↓
游戏进行中 → 实时更新匹配数、错误数、连击数
    ↓
游戏结束 → 更新完成状态、得分、时长
    ↓
学习报告 → 读取 GameSession 数据展示
```
