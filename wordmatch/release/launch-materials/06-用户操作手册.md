## 1. 应用简介

单词消消乐（WordMatch）是一款游戏化英语词汇学习应用，将消除游戏与科学记忆算法相结合，让背单词变得轻松有趣。

**核心特色：**

- **消除游戏**：通过英汉配对消除卡牌的方式巩固单词记忆，寓教于乐
- **科学记忆算法**：采用 SM-2 间隔重复算法，智能安排复习时间，提高记忆效率
- **多主题支持**：提供学术、森林、太空三套主题，满足个性化需求

**适用人群：**

- 高中生——备考高考英语
- 大学生——备考四六级、考研英语
- 英语学习者——日常词汇积累与巩固

## 2. 快速入门

### 2.1 安装与启动

1. 打开应用商店（App Store / 各大安卓应用市场）
2. 搜索"单词消消乐"
3. 点击"下载"并等待安装完成
4. 安装完成后，点击桌面图标启动应用

### 2.2 首次使用引导

**步骤1：** 启动应用后，自动进入引导页面

**步骤2：** 左右滑动浏览 3 页引导内容，了解核心玩法：
- 第1页：学习新词，掌握释义
- 第2页：消除游戏，配对巩固
- 第3页：科学复习，长效记忆

**步骤3：** 点击"开始使用"按钮，进入词库选择页面

### 2.3 选择词库

1. 浏览可用词库列表，包括：
   - **英语词库**：高考3500词、CET4、CET6、考研、IT 等
   - **领域词库**：成语、IT、诗词等
2. 点击选择目标词库，系统将加载对应词库数据
3. 选择完成后自动进入首页

## 3. 功能操作详解

### 3.1 首页操作

[截图：首页界面，显示今日任务看板]

首页是应用的核心入口，展示今日学习任务和进度统计。

- **今日任务看板**：显示新词数量和复习数量
- **"开始学习"按钮**：点击进入新词学习模式
- **"开始复习"按钮**：点击进入复习模式
- **学习进度统计**：查看累计学习数据

### 3.2 新词学习

[截图：新词学习卡片界面]

新词学习帮助您初次接触并记忆新单词。

1. 在首页点击"开始学习"，进入新词学习界面
2. 逐词浏览新单词，每张卡片展示：
   - **单词**：英文单词
   - **音标**：国际音标标注
   - **释义**：中文释义
3. 点击发音按钮 🔊 收听单词读音
4. 根据掌握情况标记：
   - 点击"认识"——标记为已掌握
   - 点击"不认识"——标记为需巩固
5. 学习完成后，自动进入消除游戏环节

### 3.3 消除游戏玩法

[截图：消除游戏界面，4x4网格]

消除游戏是核心玩法，通过英汉配对消除卡牌来巩固记忆。

**基本操作：**

1. 网格中分布英文卡牌和中文释义卡牌
2. 点击一张英文卡牌将其选中（高亮显示）
3. 再点击对应的中文释义卡牌

**匹配结果：**

- **匹配成功**：两张卡牌消除，同时播放单词发音
- **匹配失败**：卡牌抖动提示，可重新选择

**进阶玩法：**

- **Combo 连击**：连续匹配成功可触发 Combo 连击效果，连击越高特效越炫
- **通关条件**：消除所有卡牌即通关

### 3.4 复习功能

[截图：首页复习入口]

复习功能基于 SM-2 算法，智能安排复习计划。

1. 系统根据 SM-2 算法自动筛选到期需要复习的单词
2. 在首页点击"开始复习"，进入复习消除游戏
3. 复习玩法与新词消除游戏相同
4. 当没有到期复习词时，点击"开始复习"将显示"今日无需复习"提示信息

### 3.5 错词本

[截图：错词本界面]

错词本自动记录您在游戏中匹配错误的单词，方便针对性练习。

1. 在消除游戏中匹配错误的单词会自动记录到错词本
2. 进入错词本查看错误单词列表
3. 点击"重练"按钮，使用错词生成消除游戏进行针对性练习
4. 重练中匹配成功的单词将从错词本中移除

### 3.6 学习报告

[截图：学习报告界面]

每次通关后，系统自动展示学习报告。

- **今日新学词数**：当日新学习的单词数量
- **今日复习词数**：当日复习的单词数量
- **今日掌握词数**：当日成功掌握的单词数量
- **正确率**：匹配成功的比例
- **最高连击**：本局游戏中的最高 Combo 连击数

### 3.7 主题切换

[截图：主题选择界面]

应用提供 3 套精美主题，满足个性化需求。

1. 进入 **设置 → 主题选择**
2. 浏览可选主题：
   - **学术**：沉稳典雅的学术风格
   - **森林**：清新自然风格
   - **太空**：深邃宇宙风格
3. 点击主题可预览效果
4. 点击"应用"即时切换主题

### 3.8 设置

[截图：设置界面]

设置页面提供应用相关配置选项。

- **隐私政策**：查看应用隐私政策全文
- **用户协议**：查看用户协议全文
- **主题选择**：切换应用主题（详见 3.7 主题切换）
- **AI API 配置**（可选）：配置 AI 接口以启用智能功能

## 4. 常见问题

**Q: 如何更换词库？**

A: 在首页点击词库选择入口，即可浏览并切换到其他词库。切换词库后，当前词库的学习进度会保留。

**Q: 复习词太多怎么办？**

A: 系统自动限制每日复习量为 200 词，超出部分会自动分摊到后续日期，确保学习负担合理。

**Q: 如何导入自定义词库？**

A: 在词库选择页面点击"导入词库"按钮，按照提示粘贴文本内容即可完成导入。

**Q: 数据会丢失吗？**

A: 学习数据存储在本地设备中。卸载应用会删除所有数据，建议定期备份。重新安装后数据无法恢复。
