隐私政策
更新日期：2025年1月1日 欢迎使用 WordMatch 词汇学习应用（以下简称"本应用"）。我们非常重视您的隐私保护和个人信息安全。本隐私政策将帮助您了解我们如何处理您的信息。
一、我们收集的信息
本应用仅收集最少必要的数据以提供核心功能： 1. 学习进度数据：包括您已学习的单词、学习次数、正确率等，这些数据仅存储在您的设备本地，不会上传至任何服务器。 2. 词库数据：您导入或选择的词库信息，同样仅存储在设备本地。 3. 应用设置：包括主题偏好、学习计划等配置信息，存储在设备本地。 我们不会收集您的姓名、电话号码、身份证号、电子邮箱等个人身份信息。
二、信息的使用
我们使用上述信息仅用于以下目的： 1. 提供词汇学习功能，包括学习进度跟踪和复习提醒。 2. 保存您的学习偏好和应用设置。 3. 优化您的学习体验。 我们不会将您的信息用于任何其他目的，也不会将您的信息出售或分享给任何第三方。
三、网络服务说明
本应用的以下功能需要使用网络： 1. TTS 语音发音：使用有道词典 API 提供单词发音服务。当您点击发音按钮时，应用会向有道服务器发送待发音的单词文本，不包含任何个人身份信息。 2. AI 智能清洗：如果您配置了大模型 API Key，应用会将待清洗的词库文本发送至您指定的 AI 服务接口进行处理。此功能为可选功能，由您自主配置，相关数据传输遵循您所选 AI 服务的隐私政策。 除上述场景外，本应用不会主动发起任何网络请求。
四、信息的存储
1. 所有学习数据和设置信息均存储在您的设备本地，使用 SharedPreferences 和本地数据库进行持久化。 2. 我们不运营任何云端服务器来存储您的个人数据。 3. 当您卸载本应用时，所有本地数据将被一并删除。 4. 建议您定期通过应用内的导出功能备份重要学习数据。
五、信息安全
1. 我们采取合理的技术措施保护您的信息安全，包括本地数据加密存储。 2. 您自行配置的 API Key 仅存储在设备本地，不会传输至我们或任何第三方服务器。 3. 网络通信均使用 HTTPS 加密传输，确保数据传输安全。 4. 请您妥善保管设备，避免设备被他人未经授权访问。
六、未成年人保护
我们高度重视对未成年人个人信息的保护。本应用适合所有年龄段用户使用，不会主动收集未成年人的个人信息。如果您是未成年人的监护人，请您指导未成年人合理使用本应用。
七、隐私政策的变更
我们可能会适时修订本隐私政策。政策变更后，我们会在应用内通知您。若您在政策变更后继续使用本应用，即视为您同意受修订后的隐私政策约束。
八、联系我们
如您对本隐私政策有任何疑问、意见或建议，请通过以下方式联系我们： 电子邮箱：privacy@wordmatch.app 我们将尽快回复您的来信。
