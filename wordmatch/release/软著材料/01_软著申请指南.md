## 软件用途说明（200-500 字）

```
"单词消消乐"是一款基于 Android 平台开发的英语单词学习移动应用。

软件采用游戏化配对玩法，将英文单词与中文释义进行配对消除，结合艾宾浩斯遗忘曲线的间隔重复算法，让用户在轻松愉快的游戏体验中高效记忆英语单词。

主要功能：
1. 单词配对游戏：用户通过点击英文卡片和中文释义卡片进行配对，匹配正确则消除
2. 间隔重复算法：基于艾宾浩斯遗忘曲线，自动安排每日复习计划
3. AI 助记卡：为困难单词生成个性化记忆口诀
4. 词根词缀拆解：通过分析词根词缀帮助用户举一反三
5. 多种词库支持：内置四六级、考研、高考、IT 等多种词库
6. 自定义词库：支持用户导入自己的单词表
7. 学习报告：提供每日学习数据统计

技术特点：
- 移动端：使用 Flutter 跨平台框架开发
- 数据库：使用 SQLite 本地数据库存储用户数据
- 算法：实现基于艾宾浩斯遗忘曲线的间隔重复算法
- 状态管理：使用 Riverpod 进行状态管理
- 界面：Material Design 风格，支持主题切换

应用面向所有需要学习英语单词的用户群体，包括但不限于四六级考生、考研学生、高考学生、雅思托福考生、IT 从业者等。
```

## 程序鉴别材料（前后 30 页源码）

### 说明
软著申请需要提交程序源代码的前 30 页和后 30 页（总共 60 页）。需提供 PDF 格式，每页 50 行代码。

### 自动生成源码 PDF 的方法

#### 方法 1：使用 `groff` + `ps2pdf`（推荐）

```bash
# 进入项目目录
cd /Users/yiying/dev-app/xiaoxiaole/wordmatch

# 创建输出目录
mkdir -p /Users/yiying/dev-app/xiaoxiaole/wordmatch/release/软著材料/source_pdf

# 提取所有 dart 源码，按目录组织
find lib -name "*.dart" -type f | sort > /tmp/dart_files.txt

# 生成第一个 30 页（前 30 页代码）
head -100 /tmp/dart_files.txt | xargs cat > /tmp/wordmatch_source_first30.txt
wc -l /tmp/wordmatch_source_first30.txt  # 应该超过 1500 行

# 生成最后 30 页（后 30 页代码）
find lib -name "*.dart" -type f -newer /tmp/dart_files.txt 2>/dev/null
tail -100 /tmp/dart_files.txt | xargs cat > /tmp/wordmatch_source_last30.txt
```

#### 方法 2：使用 `pandoc` + `wkhtmltopdf`

```bash
# 安装 pandoc 和 wkhtmltopdf
brew install pandoc wkhtmltopdf

# 提取 dart 源码并合并到一个文件
find /Users/yiying/dev-app/xiaoxiaole/wordmatch/lib -name "*.dart" -type f | \
  xargs cat > /tmp/wordmatch_source_all.txt

# 转换为 PDF
pandoc /tmp/wordmatch_source_all.txt \
  -o /tmp/wordmatch_source.pdf \
  --pdf-engine=wkhtmltopdf \
  -V geometry:margin=2cm \
  -V fontsize=10pt
```

#### 方法 3：手工整理（最稳妥）

1. 打开 `lib/main.dart` 作为首页
2. 依次选择重要的源文件（按功能模块）
3. 复制到 Word 文档，每页 50 行
4. 添加目录页和页码
5. 导出为 PDF

### 2. 选择办理方式
| 方式 | 周期 | 费用 | 难度 |

| **自己办理** | 30-60 工作日 | 免费（仅证书工本费） | 高 |
| **普通代理** | 30-40 工作日 | 300-800 元 | 中 |

### 3. 提交申请
- 线上提交：中国版权保护中心官网 https://www.ccopyright.com.cn
- 线下提交：现场办理

### 4. 受理审查
- 形式审查：5-10 个工作日
- 实质审查：20-50 个工作日

### 5. 领取证书
- 审查通过后下发《计算机软件著作权登记证书》
- 电子证书或纸质证书（自取 / 邮寄）
