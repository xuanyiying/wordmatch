1. 单词配对游戏化学习
2. 艾宾浩斯间隔重复算法
3. AI 助记卡生成
4. 词根词缀拆解
5. 多种词库支持
6. 自定义词库导入
7. 学习数据统计
8. 100% 本地存储，隐私优先
