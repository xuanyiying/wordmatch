# 应用截图制作指南

## 截图规格

### 通用要求
- **最小尺寸**：320px
- **最大尺寸**：3840px
- **推荐尺寸**：1080×1920（竖屏）或 1920×1080（横屏）
- **格式**：PNG 或 JPEG
- **文件大小**：每张 ≤ 8MB
- **数量**：5-8 张

### 各商店特殊要求

| 商店 | 推荐尺寸 | 数量 |
|---|---|---|
| 华为 | 1080×1920 | 5 张 |
| 小米 | 1080×1920 | 5 张 |
| 应用宝 | 1080×1920 | 5-8 张 |
| OPPO | 1080×1920 | 5 张 |
| vivo | 1080×1920 | 5 张 |
| App Store | 1242×2688 (iPhone 6.5") | 5-10 张 |
| Google Play | 1024×1920 至少 2 张 | 2-8 张 |

## 截图设计模板

### 通用布局
```
┌─────────────────────────┐
│  [状态栏：00:00 信号 100%] │  ← 模拟手机状态栏
├─────────────────────────┤
│                         │
│                         │
│   [应用截图主区域]      │  ← 占 70% 高度
│   实际游戏界面          │
│                         │
│                         │
├─────────────────────────┤
│                         │
│   [标题文案]            │  ← 大字标题
│   简短描述              │  ← 一行小字
│                         │
└─────────────────────────┘
```

### 推荐配色
- 背景：白色 / 浅灰
- 标题：深色（#2C3E50）
- 副标题：灰色（#7F8C8D）
- 强调色：#3498DB（蓝）/ #2ECC71（绿）

### 工具推荐
- **Figma**：免费、模板丰富
- **Sketch**：Mac 平台首选
- **Canva**：在线模板
- **AppMockUp**：专门的 App 截图工具
- **Screenshot.pro**：在线工具

## 图标设计要求

### 规格
- **尺寸**：512×512 (PNG)
- **格式**：PNG（带透明通道）
- **自适应图标**（Android 8+）：前景 + 背景分离

### Android 图标尺寸要求
| 密度 | 尺寸 | 位置 |
|---|---|---|
| mdpi | 48×48 | mipmap-mdpi |
| hdpi | 72×72 | mipmap-hdpi |
| xhdpi | 96×96 | mipmap-xhdpi |
| xxhdpi | 144×144 | mipmap-xxhdpi |
| xxxhdpi | 192×192 | mipmap-xxxhdpi |

### 圆角要求
- 圆形图标（iOS 风格）
- 圆角矩形（Android 12+）
- 保持中心 41% 区域是核心元素

## 现状

当前使用 Flutter 默认图标（蓝色 Flutter Logo）。**强烈建议** 上架前替换为：
1. 自定义图标（含"单词消消乐"主题元素）
2. 设计稿

### 临时方案
如果暂时没有设计资源：
1. 用 Figma/Canva 在线设计
2. 参考 Fiverr 找设计师（$5-30）
3. 用 AI 工具生成（Midjourney、GPT-4o）
